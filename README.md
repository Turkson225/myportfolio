# Turkson225 — IoT & Embedded Systems Portfolio

A static, GitHub Pages-ready engineering portfolio covering connected devices, embedded systems, robotics, flight systems, power monitoring, automation and digital products.

## Featured work

SmartGuard Home Security · Flight Command Center · Flight Deck V1 · Smart Circuit Isolator · ESP32 Gas Detector · ESP32 Relay Control · Turk Robotics · Turk Innovation · InnovateX Engineering Club · Jedi's Store · Turk Electronics.

## GitHub Pages

Enable **Settings → Pages → Deploy from a branch → main → /(root)**.

Expected URL:

https://turkson225.github.io/turk-robotics-website/

No build step is required. The site uses plain HTML, CSS and JavaScript.

## Portfolio design

The site is built as an engineering showcase rather than a generic personal portfolio. It includes:
- responsive dark technical visual language
- animated system-map hero
- searchable project categories
- project detail dialogs with GitHub/live links
- systems architecture section
- embedded/IoT technology stack
- engineering approach and contact section
- reduced-motion support and mobile navigation

Project content is grounded in the actual repositories and project documentation available through the connected GitHub account.
